# jfx-coloring-book
In this repository is a simple JavaFX project of a coloring book application. The user can draw on the image to color it, and cycle through different images to play around with

# How does it work?
Upon booting, the user can draw on the image (represented by a canvas object). There are sections to resize the brush and change the color. At the very bottom are buttons to cycle through the images (next and previous). In the file menu, the user can save the image, clear the image to its original state, or exit.
